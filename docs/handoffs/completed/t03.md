## Outcome

Current facts drive both regeneration modes. Same-minute, older and quoted
updated scalars no longer strand stale status; delayed pure arbitration remains
deterministic and immediately projects its resulting execution state. CLI and
renderer share a visible source projection and verified input digest. Human,
agent and raw dashboard views use the same current output. SQLite is disposable.

Visibility runs before deriving titles, relationships, child routes, staged
rollups, counts and overflow. Private item ownership excludes documents and
proposals; private documents are also filtered through the pure facts/query API.
Raw routes cannot expose hidden files or transaction snapshots. Public previews
omit lines containing known private identifiers/titles without changing source.
Unverifiable carried dashboard entries/strays are omitted; CLI regen retains
prior bytes in the recoverable transaction journal for explicit item capture.

Triage sets sticky `review: needed` while preserving execution status and blockers.
Unresolved arbitration likewise uses review metadata without status absorption.
Legacy `status: needs-review` remains accepted, with unknown prior execution state
shown as `review: legacy-unknown`; no automatic todo migration. Terminal items
flagged for review remain discoverable in the needs-review query. T05's packet
records that checkpoint readiness must be separate from review and status.

Children are promoted when parents become terminal, archived, private or missing;
invalid parent cycles retain routes while validation still reports structural
errors. Query roots and dashboard roots use the same nesting computation.
`query active --now` supports reproducible age-off checks.

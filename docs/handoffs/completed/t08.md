  CLI schema/directory checks, creation, dashboard cards and web labels/routes
  consume it. Schema-only custom type support is explicitly withdrawn; a supported
  addition needs one catalog entry and its schema. Legacy cards remain compatible.
- Bundled `decision` and `finding` schemas define scope, source provenance,
  Observations, Uncertainty and review; reviewed records name reviewer/date.
  Base `superseded-by` retains replacement relationships without moving files.
  Validation checks resolution/cycles and substantive reviewed/observed metadata.

  carry provenance/supersession edges and expose scope, review and verification.
  Records work through creation, validation, queries, cards, search and detail views.

  visible work, and dated Markdown impact reports. Reports deduplicate explicit
  outcome identities, retain archive/source links, and separate claims, recorded
  observations, evidence references and unresolved verification.

  incomplete source provenance cannot silently become report evidence. Private,
  redacted, dropped, superseded, non-done or review/staged source work cannot add
  report text or counts. Reports never fetch external evidence or infer impact
  from journal activity or related tasks.

  `report`, strict date inputs, generic required-field defaults, compatible schema

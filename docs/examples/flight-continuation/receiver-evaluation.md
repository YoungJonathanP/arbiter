- The initial batched read exceeded the outer tool display limit despite logging
  the complete source bytes. The agent reported recovering the omitted protocol
  sections, and both reads exist in the trace. Exact original delivered bytes and
  completeness of comprehension cannot be established from the byte logger.
- Concurrent logger calls chose the same output filename from an entry count.
  One 2,530-byte output was overwritten by a 27,395-byte output. Both ledger entries
  survive, but the first raw output does not survive at that path. Totals describe
  generated output, not a complete independently replayable display transcript.
- Known emitted tool output plus the saved verification script already use 21,771
  bytes of the proposed 24,576-byte working reserve. Command inputs, reasoning,
  framing and the unfinished outgoing checkpoint/report are not fully accounted.
  The receiver therefore did not demonstrate completion within that reserve.
- Host instructions, tool definitions, usable context/token capacity and exact
  delivered context remain unknown. Source-byte headroom neither measures them
  nor proves session admission. Parent messages/intervention are additional
  unmetered orchestration context. No runtime budget controller was introduced.

This sample exposes incomplete transport/budget accounting and interrupted capture;
it does not establish a measured count of all missed constraints. No unauthorized
lifecycle/source mutation was observed. Receiver stale-state prevention and reserve
stop/checkpoint behavior were not reached and remain unmeasured.
